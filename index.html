使用场景

查阅公开资料与跨境站点

当你需要打开海外文档、公开数据库或协作后台时，先在客户端导入魔戒订阅，再选择可用节点访问，减少因链路限制造成的反复刷新。

影音内容浏览

在支持解锁的线路上观看或收听常见流媒体。实际可播放范围取决于当时节点与套餐能力，连接后以客户端内线路列表为准。

远程办公与云服务

邮件、网盘、设计协作与代码托管等工具，适合用桌面客户端常驻连接，避免来回开关。

出行与多网络切换

宿舍、咖啡馆或差旅途中网络质量不稳定时，可改换节点继续访问常用站点。

同一订阅覆盖多台设备

手机与电脑可共用一条机场订阅，只要同时在线数量不超过所选套餐即可。

客户端选择

魔戒通过通用代理客户端工作，而不是单独的封闭 App。选对客户端，是整条加速链路里最关键的一步：系统不同，导入方式与分流能力也不同。

按系统挑选

Windows 与 macOS 多用 Clash、sing-box 一类桌面内核；Android 可选用同类图形客户端；iOS 常见为 Shadowrocket 等支持订阅的工具。请只从你信任的来源获取安装包。

导入前核对三件事

确认系统版本能运行该客户端；确认客户端支持订阅 URL 或二维码导入；确认你准备开启的是规则分流还是全局模式。完成后再进入套餐区获取订阅。

操作说明

以下流程适用于大多数机场订阅。若某一步与你使用的客户端文案不一致，以客户端内按钮名称为准。

1. 选定客户端并完成安装

回到客户端选择区，按设备下载并安装。安装后先不要急着连网，留到导入订阅之后。

2. 选择套餐并复制订阅链接

在套餐区域完成订阅，进入用户中心复制订阅地址。不要把该链接发到公开群组或网页。

3. 在客户端中导入并更新

打开「订阅 / 从 URL 导入」，粘贴链接后保存，执行一次更新，直到节点列表出现。

4. 选择节点并开启系统代理

挑选延迟可接受的节点，打开 VPN 或系统代理。浏览器访问目标站点，确认页面可打开后再去处理分流规则。

5. 日常维护

流量将尽、节点超时或客户端报错时，优先更新订阅并更换节点。设备数量超出套餐上限时，先在其中一台断开。

常见问题

魔戒是什么服务？

魔戒是机场订阅型网络加速服务，也常被称作 VPN 梯子或加速器入口。用户完成订阅后，把链接导入客户端即可连接可用线路，用于跨境访问与日常加速。

为什么要把客户端选择放在最前面？

没有可导入订阅的客户端，套餐本身无法工作。先确认系统与客户端匹配，再付款复制链接，能避免装错软件或找不到「订阅」入口。

如何把魔戒订阅导入客户端？

在用户中心复制订阅 URL，于客户端选择从 URL 添加或扫描导入，保存后点击更新。列表出现节点后，再开启代理或 VPN 模式。

连接失败时先检查哪些项？

确认订阅未过期、客户端已成功更新、本机系统时间正确，并尝试切换节点。公司或校园网若拦截代理端口，可改用客户端提供的其他协议配置（若套餐支持）。

多台设备可以同时使用吗？

可以，但同时在线数量受套餐限制。请在套餐卡片中查看设备上限，超出后可能出现掉线。不用的终端记得断开。

流量如何理解，用尽了怎么办？

一般按上行加下行合计。具体额度以所选套餐为准。用尽后等待结算周期重置，或在用户中心变更套餐。本页不重复抄写各档数值。

可以在本页直接下载客户端吗？

客户端入口集中在「客户端选择」一节，由页面统一注入。请勿使用来路不明的安装包，也不要相信任何私聊发送的所谓高速节点文件。
